# My WebGIS Project

基于 AI Agent 的 WebGIS 空间分析平台（学习项目）。

## 技术栈

- **后端**：Node.js + Express + WebSocket
- **前端**：JavaScript + OpenLayers
- **AI Agent**：LLM API（OpenAI 兼容接口）
- **地图服务**：GeoServer
- **GIS 分析**：turf.js

## 目录结构

```
my-webgis-project/
├── README.md
├── backend/          # Node.js 后端
├── frontend/         # 前端页面
│   ├── index.html
│   ├── js/

```
