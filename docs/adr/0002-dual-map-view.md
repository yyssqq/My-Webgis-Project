# ADR-0002：双地图视图（OpenLayers 2D + Cesium 3D）

- 状态：已接受
- 日期：2026-08-02

## 背景

原前端使用 Cesium 3D 球体。阶段 C 需要地图标绘（画点线面/标注），Cesium 的矢量编辑体验差；
OpenLayers 2D 的绘图/标注/叠加能力强。

## 决策

同时引入 OpenLayers（2D，分析/绘图）与 Cesium（3D，展示），提供视图切换。

## 理由

- 各取所长：OL 2D 做分析交互与标绘，Cesium 3D 做成果展示
- 阶段 C"地图标绘专家"需要 2D 绘图能力

## 后果

- 前端依赖两套地图库，体积增加
- 需要维护两套渲染逻辑（图层数据结构需两者兼容：GeoJSON 通用）
